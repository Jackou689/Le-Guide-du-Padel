# Checklist d’activation de Google AdSense

Cette checklist reprend la configuration convenue : le message relatif aux réglementations européennes est géré dans Google AdSense. Le site n’ajoute pas de CMP artisanale et le lot 8C n’introduit pas de bouton « Tout refuser ».

## Avant activation

- [ ] Finaliser la micro-entreprise et le lot 8B.
- [ ] Finaliser les mentions légales et l’identité de l’éditeur.
- [ ] Vérifier le domaine `leguidedupadel.fr` dans AdSense.
- [ ] Vérifier le fichier `ads.txt` généré ou demandé par AdSense.
- [ ] Ouvrir **Confidentialité et messages > Réglementations européennes** dans AdSense.
- [ ] Conserver le type de message et les choix déjà retenus pendant la configuration du compte.
- [ ] Ne pas ajouter de bouton « Tout refuser » dans le code du site.
- [ ] Ne pas ajouter de second bandeau de consentement en parallèle.
- [ ] Vérifier la liste des fournisseurs de technologie publicitaire.
- [ ] Mettre à jour la politique de confidentialité avec la date réelle d’activation.

## Ajout technique

- [ ] Ajouter le script AdSense officiel une seule fois selon les instructions du compte.
- [ ] Remplacer progressivement les placeholders par les unités publicitaires réelles.
- [ ] Ne jamais afficher simultanément placeholder et annonce dans le même emplacement.
- [ ] Tester le message AdSense depuis une navigation privée et une localisation EEE.
- [ ] Vérifier que le lien de gestion des choix fourni par la solution Google reste accessible selon sa configuration.

## Recette après activation

- [ ] Le message configuré dans AdSense s’affiche comme prévu lors d’une première visite concernée.
- [ ] Le parcours « Consentir » fonctionne.
- [ ] Le parcours « Gérer les options » fonctionne.
- [ ] Un visiteur peut modifier son choix via le mécanisme fourni par Google.
- [ ] Aucune CMP concurrente ou interface artisanale n’est chargée.
- [ ] La navigation reste possible quel que soit le choix effectué.
- [ ] Les annonces ne créent aucun débordement à 320, 360, 390 et 430 px.
- [ ] Le mode sombre du site reste lisible autour des emplacements publicitaires.
